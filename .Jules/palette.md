## 2023-10-06 - Fixing nested interactive controls in Session Cards
**Learning:** Found an accessibility anti-pattern where a `div` with `role="button"` contained a nested delete `<button>`. Using native `<button>` elements with absolute positioning is a cleaner, more accessible approach. Adding contextual `aria-labels` (e.g., `aria-label={"Delete session ${session.videoName}"}`) makes the UI much more screen-reader friendly than generic "Delete Session" labels.
**Action:** Use a non-interactive `relative` container `div`, an `absolute inset-0` primary `<button>`, and `relative z-10` for secondary actions to prevent nested interactive controls. Ensure textual content has `pointer-events-none` so it doesn't block the absolute button. Add specific names to ARIA labels.
